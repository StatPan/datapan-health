# Security reporting

This repository does not currently publish a verified private security-report
channel. Do not report vulnerability details in a public GitHub issue.

Before this project accepts external security reports, a maintainer must
publish and verify one private channel (for example, GitHub private
vulnerability reporting or a monitored security contact) and state the
supported versions and response expectations here. Until that happens, this
repository makes no promise of a private reporting route or response time.

Public issues remain appropriate for non-sensitive bugs and documentation
problems only. Remove credentials, provider URLs, response data, and any
exploit details from those reports.
