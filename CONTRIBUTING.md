# Contributing to Datapan Health

Thanks for considering a contribution.

## License for contributions

No contributor license agreement is required for this repository. By
submitting a pull request or other contribution for inclusion, you confirm
that you have the right to submit it and intend it to be available under the
repository's [Apache-2.0 LICENSE](LICENSE), unless you clearly mark it as not
a contribution before submission.

Do not add copied provider data, API documentation, third-party source, or
generated dependency artifacts unless their separate terms, provenance, and
required notices have been reviewed. The Apache-2.0 license does not change
those terms.

## Working agreement

Keep changes narrowly scoped, preserve the public redaction boundary, and run
the relevant checks documented in `AGENTS.md` and the `Makefile`. New or
changed third-party components need an update to [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)
and any release inventory required for their distribution.

Do not place credentials, full provider URLs, response rows, or personal data
in issues, commits, test fixtures, logs, or pull requests.
